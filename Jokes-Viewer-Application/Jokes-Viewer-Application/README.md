# 😂 Joke Viewer (React)

A simple and clean Joke Viewer app built using React.  
This app fetches random jokes from an API and displays them in a minimal UI.

---

## 🚀 Features

- Fetches random jokes from API
- Displays joke content in a clean card UI
- Loading and error state handling
- Refresh button to get a new joke
- Simple and responsive design

---

## 🛠️ Tech Stack

- React (Hooks)
- JavaScript (ES6+)
- Fetch API
- CSS

---

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/coderTejas565/joke-viewer.git
````

### 2. Navigate to project

```bash
cd joke-viewer
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the app

```bash
npm run dev
```

---

## 🌐 API Used

* Random Joke API (FreeAPI)
* Endpoint:
  `https://api.freeapi.app/api/v1/public/randomjokes/joke/random`
