# 🚀 React API Projects Collection

A curated collection of **8 beginner-to-intermediate React projects** focused on mastering API integration, UI design, state management, and real-world frontend development patterns.

This repository demonstrates practical implementation of **data fetching, authentication flows, and dynamic UI rendering using React**.

---

## 📌 Tech Stack

* React (Vite)
* JavaScript (ES6+)
* Fetch API
* CSS3 (Custom Styling)
* FreeAPI.app (REST APIs)
* HTML5

---

# 📁 Projects Overview

## 1. 👤 Random Users UI

A dynamic user profile generator that fetches random user data and displays it in a structured card layout.

### Features:

* API integration (Random User endpoint)
* User profile card UI
* Loading and error handling
* Responsive design

---

## 2. 🍽️ Meals Listing Interface

A meal discovery UI that lists food items with structured details.

### Features:

* Meals grid layout
* Category-based display
* Image + title + metadata rendering
* Clean responsive UI

## 3. 🛍️ Product Listing Interface

An e-commerce style product catalog built using API data.

### Features:

* Product grid layout
* Image, title, category, price display
* Card-based UI design
* Responsive layout system

## 4. 🃏 Joke Viewer App

A simple application that displays random jokes from an API.

### Features:

* Fetch random jokes
* Refresh functionality
* Minimal UI design
* Instant content updates

## 5. 📝 Quotes Listing App

A motivational quotes viewer that renders quotes dynamically.

* Quote content rendering

## 6. 🐱 Random Cat Viewer

A cat breed explorer that displays detailed information about cats.

### Features:

## 7. 🎥 YouTube Video Listing UI
